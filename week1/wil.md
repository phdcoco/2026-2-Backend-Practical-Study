# 테스트 코드
테스트 코드는 현재 작성된 코드를 굳이 서버를 돌릴필요 없이 간단히 테스트 해볼 수 있게하는 장치이다.  
## TDD
TDD는 테스트를 중점으로 하는 개발방식으로  
```
1. 일단 명세대로 만들고
2. 테스트를 통과할 수 있게 만든 후
3. 2번을 리펙터링하는 방식이다.
```
이는 요구사항을 명확하게 함과 동시에 모듈간 결합도를 낮추는 효과가 있어 객체지향 프로그래밍에 걸맞다.
## Mock
Mock는 가짜객체로 테스트 상황에서 DB나 외부 서버에 관계 없이 빠르게 정해진 답을 주고 받을 수 있는 객체이다.

# @Setter
@Setter는 객체 내의 변수를 설정할 수 있게 하는 요소로, 만약 훗날 외부 객체로 @Setter를 이용하여 내용을 편집할 수 있다.  
이때, 내부로직을 벗어난 방식으로 강제 개입하므로 유지보수에 큰 위험부담이 따른다.

# TDA와 @Getter
TDA는 객체의 데이터에 대해 간섭하지 않고 실행시킬 사항을 **전달**하는 방식이다.
Getter는 값 조회에 불가하니 상관이 없다.
